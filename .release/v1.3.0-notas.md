**Studio IA Local 1.3.0**: motores de inferencia con elección automática, y RAM, VRAM o NPU para cada modelo.

## Descargas
| Archivo | Para qué |
|---|---|
| `StudioIA-Windows-x64.zip` | Windows 10/11 x64, portátil: descomprimir y abrir `StudioIA.exe` |
| `StudioIA-Android-Snapdragon.apk` | Móviles con Snapdragon: añade Qualcomm Genie (NPU Hexagon, GPU Adreno, CPU) |
| `StudioIA-Android.apk` | Resto de móviles Android 8+ (arm64) |
| `SHA256SUMS.txt` | Huellas para comprobar las descargas |

Instala solo una de las dos APK. Las dos actualizan la 1.2.1 sin perder datos.

## Novedades
- Motores en el PC: Ollama, llama.cpp, ONNX Runtime GenAI, OpenVINO GenAI, LiteRT-LM, ExecuTorch, MLC LLM, TensorRT-LLM y Qualcomm Genie.
- Cómo se elige el motor de cada modelo: primero lo que fijes a mano, después la prueba de velocidad «⚡ Medir» y, si no hay ninguna de las dos, una estimación según el formato del modelo y tu equipo.
- Ubicación de cada modelo: GPU (VRAM), CPU (RAM), mixta (eliges cuántas capas van a la GPU) o NPU.
- Motores en Android:
  - ONNX Runtime GenAI: CPU.
  - ExecuTorch: CPU o GPU con Vulkan.
  - LiteRT-LM: CPU o GPU.
  - Qualcomm Genie, solo en la APK Snapdragon: NPU, GPU o CPU.
- Descarga de modelos de Hugging Face desde ⚙️ Modelos.

Manuales en [`docs/pdf`](https://github.com/JosebaMuro/Prueba/tree/main/docs/pdf).
